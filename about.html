Structuring content

Writing semantic markup that search engines and screen readers understand.

I use headings, sections, lists and landmarks to give every page a clear structure before adding any style.

Styling and layout

Making pages look good with Flexbox, Grid and a consistent design system.

I organize styles in a dedicated stylesheet and use variables for colors and fonts so changes stay easy.

Tracking my work

Using commits to document progress and GitHub to share the code.

Small, clear commits make it easy to see how a project grew, and to undo mistakes safely.

Every screen size

Building mobile-friendly layouts with Bootstrap's grid and media queries.

I test pages at phone, tablet and desktop widths so nothing breaks or overflows.

Where I'm heading

Learning JavaScript to make my pages interactive.

After HTML and CSS, I want to learn the DOM, small interactive widgets and eventually a front-end framework.
