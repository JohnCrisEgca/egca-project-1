# JohnCrisEgca | Personal Portfolio Website

A multi-page personal portfolio built with HTML and CSS, using the layout of the
[Mentor](https://bootstrapmade.com/mentor-free-education-bootstrap-theme/) Bootstrap template by BootstrapMade.

## Pages

| Page | File |
| --- | --- |
| Home | `index.html` |
| About | `about.html` |
| Projects | `projects.html` |
| Project details | `project-details.html` |
| Skills | `skills.html` |
| Journey | `journey.html` |
| Roadmap | `roadmap.html` |
| Contact | `contact.html` |

## Structure

```
egca-project-1/
├── index.html
├── (other pages).html
├── styles/
│   └── main.css
└── assets/
    ├── img/   images, profile picture, favicon
    └── js/    main.js
```

Bootstrap, Bootstrap Icons and AOS are loaded from the jsDelivr CDN, so an internet connection is needed to see the full styling.

## Run locally

Open `index.html` in any browser. No build step needed.
