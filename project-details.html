Personal Portfolio Website

This portfolio is my first complete web project. It brings together everything I've learned so far: semantic HTML, a custom stylesheet, responsive layouts and version control.

The site is organized into separate pages for my story, projects, skills, learning journey and contact details, and it is published online with GitHub Pages.

What I Practiced

  • Planning a multi-page site structure
  • Writing semantic, accessible HTML
  • Styling with a custom stylesheet
  • Responsive layouts with Bootstrap's grid
  • Committing work in small, clear steps
  • Deploying with GitHub Pages
